## Explanation of Incorrect Predictions

### a.dtype
I predicted int, but the actual data type is uint8.
The array was defined with dtype=np.uint8.

### a.shape
I predicted (3*2), but the actual shape is (2, 3).
The array has 2 rows and 3 columns.

### a.nbytes
I predicted 8 bytes, but the actual result is 6 bytes.
The array contains 6 elements, and each uint8 element uses 1 byte.

### Overflow
In uint8, values must be between 0 and 255.
When arithmetic results exceed this range, overflow occurs.

For example:
250 + 10 = 260, but the stored result is 4.

When subtracting 20 from 10, the stored result is 246.

When multiplying 200 by 2, the stored result is 144.
